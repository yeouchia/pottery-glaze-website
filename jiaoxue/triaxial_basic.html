陶瓷釉藥的奧秘：三角座標基礎教學

不再憑感覺調配！透過科學化的「三角座標試驗法」，帶您建立清晰的釉藥實驗地圖，精準找出理想配方。

一、 什麼是「三角座標試驗法」？

釉藥是由多種原料混合而成。但是，如果我們只是憑經驗：
「這個多加一點、那個少加一點。」
就很難知道到底是哪一個比例造成釉面變化。

因此，陶瓷釉藥實驗發展出一種非常實用的方法：三角座標試驗法（Triaxial Blend）

它的基本概念非常簡單：選擇三種原料，利用一個等邊三角形，把三種原料的不同比例排列出來，再逐一燒製比較。

三種原料 ➔ 三角座標 ➔ 不同比例 ➔ 不同釉方 ➔ 試片燒成 ➔ 觀察釉面 ➔ 找出理想配方

利用三種原料的不同比例進行系統性試釉，並藉由燒成後的試片比較釉藥特性。

二、 為什麼叫「三角座標」？

因為我們一次研究三種原料，所以使用一個三角形。三角形的三個頂點，就代表三種不同的原料。

例如本課程指定：
A頂點：長石
B頂點：碳酸鈣
C頂點：石英

📌 三個頂點代表「100%」

這是學習三角座標最重要的第一個觀念。

  • A頂點： 代表 A＝100%（因此 B＝0%, C＝0%）
  • B頂點： 代表 B＝100%（因此 A＝0%, C＝0%）
  • C頂點： 代表 C＝100%（因此 A＝0%, B＝0%）

★ 結論：頂點＝某一種原料 100%。

📌 三角形的三條「邊」代表什麼？

這個觀念非常重要。假設 A＝長石，那麼：距離 A 最遠的那一條邊，就代表 A＝0%。

因此：
越靠近某個頂點 → 該原料越多
越遠離某個頂點 → 該原料越少

(圖1) A原料 (長石) 比例遞減
(圖2) B原料 (碳酸鈣) 比例遞減
(圖3) C原料 (石英) 比例遞減

三、 平行線與交叉點的意義

📌 平行線就是「比例刻度」

三角座標真正有用的地方，是我們可以在三角形裡面畫出很多條平行線。這些線就像「刻度尺」（如上圖的 80, 60, 40, 20, 0）。實際繪製時，是由三個方向建立互相平行的等比例線。

📌 為什麼一個「點」就是一個「釉方」？

這是三角座標最核心的概念。例如我們在三角形中找到一個點，這個點同時可以讀出：

A＝40% ｜ B＝40% ｜ C＝20%
A ＋ B ＋ C ＝ 100%

如果我們要做 100g 的釉藥，就直接換算成實際重量：

原料 比例 實際重量
A 長石40%40g
B 碳酸鈣40%40g
C 石英20%20g
總和100%100g

★ 一個交叉點 ＝ 一組釉藥配方 ★

四、 21點與66點的實驗地圖

📌 為什麼要做這麼多配方？

假設只做一種配方，燒完不好，我們只知道「這個配方不好」，但是不知道「那怎麼改？」。

如果我們一次做 21 組或 66 組不同的比例，就可以看到：
原料比例改變 ➔ 釉面逐漸改變 ➔ 找到比較好的區域

📌 21點與66點的關係

可以把它想像成找尋寶藏的過程：

  • 🗺️ 21點 ＝ 地圖： 先找出「哪個區域比較有可能成功？」 (初步篩選、大方向搜尋)
  • 🔍 66點 ＝ 放大地圖： 再仔細尋找「這個區域裡面，到底哪一個比例最好？」 (細部搜尋)
口訣：「21點找方向，66點找細節。」
21點 (5等分) - 找方向
66點 (10等分) - 找細節

五、 實驗原料的角色與限制

以本課程指定的「長石＋碳酸鈣＋石英」為例，這三種原料可以用來建立一個非常直觀的基礎實驗：

長石

提供多種釉藥成分
碳酸鈣

助熔作用
石英

玻璃質來源

注意：一種原料不一定只扮演一種角色

例如：長石並不是「只有助熔劑」。它本身含有 K₂O、Na₂O、Al₂O₃、SiO₂、CaO 等成分，所以長石是一種「複合型原料」。學生要清楚區分「原料」與「原料裡面的氧化物」這兩個概念。

📌 三角座標法的優缺點

優點
  • 簡單： 學生容易理解。
  • 直觀： 比例直接轉換成重量。
  • 容易比較： 不同交叉點就是不同釉方。
  • 系統化： 系統化實驗，不是憑感覺亂加。
  • 找最佳區： 燒成後可直接比較整組試片。
缺點
  • 數量龐大： 66點全做需大量原料與時間。
  • 變數限制： 只能研究三種原料的變化。
  • 非化學組成： 它是原料比例的實驗方法，無法直接代表完整的化學組成分析。

六、 三角座標 vs. 塞格式 (Seger Formula)

當理解三角座標後，可以開始認識另一種更進階的化學方法。兩者最大的差異在於：

比較項目 🔺 三角座標法 🧪 塞格式 (Seger Formula)
思考方式原料比例化學氧化物比例
基礎單位重量百分比莫耳／當量計算
難度⭐⭐⭐⭐⭐⭐⭐
適合對象初學、實驗進階釉藥研究
優點直觀、容易操作化學分析較精確
缺點受原料本身成分變化影響計算較複雜

建議教學順序： 先學三角座標 ➔ 再理解原料與氧化物 ➔ 最後才進入塞格式。

📌 燒成後要觀察什麼？

三角座標不是「配完就結束」，真正重要的是燒完以後的比較。每一個試片都要觀察：

  • ① 是否熔融？ 釉有沒有真正融化？
  • ② 是否流釉？ 釉是否流得太厲害？
  • ③ 光澤： 是亮面、半光還是霧面？
  • ④ 透明度： 是透明、半透明還是不透明？
  • ⑤ 色彩： 呈現什麼顏色？
  • ⑥ 表面缺陷： 有沒有針孔、氣泡、縮釉、裂釉或流釉？

三角座標的真正價值在於讓學生建立：「實驗 → 記錄 → 比較 → 修正」 的科學思考，讓陶藝不再只是憑經驗調釉，而是有系統地研究釉藥。

🌟 給學生的最後總結

三角座標法可以理解成：
「用三角形建立一張釉藥實驗地圖。」

🔺 三角座標四句話口訣：

  1. 三個頂點，代表三種原料。
  2. 頂點100%，對邊0%。
  3. 一個交叉點，就是一組釉方。
  4. 三種比例加起來，永遠等於100%。

「21點找方向，66點找細節。」
