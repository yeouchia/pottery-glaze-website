燒窯技術

玻璃質如何結合在陶瓷？（燒成技術~還原燒）

釉藥 電窯 瓦斯窯
摘要： 還原燒，是陶瓷燒成技術中非常重要的一種燒成方式。簡單來說，就是在燒成過程中，控制窯內氧氣量，使窯內形成氧氣不足的還原氣氛。這不僅影響金屬氧化物的發色，也關乎釉藥玻璃質與陶瓷坯體的結合變化。

一、什麼是還原燒？

還原燒，是陶瓷燒成技術中非常重要的一種燒成方式。簡單來說，就是：在燒成過程中，控制窯內氧氣量，使窯內形成氧氣不足的還原氣氛。

當窯內氧氣不足時，燃燒中的氣體會尋找氧氣來源，進而影響陶土與釉藥中的部分金屬氧化物。因此，還原燒會改變：

  • 釉色
  • 金屬氧化物的發色
  • 坯體表面
  • 釉面質感
  • 窯變效果

所以，同一個釉藥配方：氧化燒，可能呈現一種顏色。還原燒，則可能呈現完全不同的顏色。這就是還原燒最迷人的地方。

二、還原燒的基本原理

陶瓷與釉藥中常含有不同的金屬氧化物。例如：氧化鐵、氧化銅、氧化鈷、氧化錳。這些金屬氧化物在不同燒成氣氛中，可能產生不同的化學狀態與顏色。

在氧氣較充足的氧化燒中，金屬氧化物通常保持較高的氧化狀態。而在還原燒中：窯內氧氣供應減少，使部分金屬氧化物發生還原反應。因此，釉藥中的金屬氧化物可能產生不同的發色。

例如，含鐵釉在氧化與還原氣氛下，可能呈現不同的色彩變化；含銅釉也可能因燒成氣氛不同而出現明顯差異。

所以，還原燒的效果並不是只由釉藥配方決定。可以簡單理解為：

還原燒效果 ＝ 釉藥配方 + 溫度 + 時間 + 還原程度 + 冷卻方式

三、為什麼還原燒的效果較有變化？

氧化燒通常比較容易控制。但是還原燒除了控制溫度之外，還必須控制：氧氣量、燃料量、空氣供應、燒成時間、還原開始的時機、還原的強弱、冷卻方式。

因此：還原燒比氧化燒多了一個重要的變化因素，就是窯內氣氛。只要窯內氣氛發生改變，作品的顏色與釉面效果就可能不同。這也是為什麼：同一種釉藥，使用不同的還原程度，可能產生不同的結果。

四、還原燒的三個基本概念

還原燒並不是只有「還原」與「不還原」兩種狀態。實際燒成時，可以概念性地理解為：

  • 1. 弱還原：窯內仍有一定的氧氣，但氧氣量開始減少。還原效果較溫和。
  • 2. 中度還原：窯內形成較明顯的還原氣氛。這是許多還原燒成中需要控制的重要狀態。
  • 3. 強還原：窯內氧氣量明顯不足。還原作用較強。但要注意：強還原並不一定代表效果最好。如果還原過度，可能造成釉色失去原本預期的效果。

因此，真正重要的不是：還原越強越好。而是：找到適合釉藥與坯體的還原程度。

五、還原燒與釉色的關係

還原燒最大的特色，就是能改變金屬氧化物的發色。不同的著色氧化物，對還原氣氛的反應並不相同。因此，同一種釉藥在不同氣氛下可能出現不同效果。

  • 含鐵釉：可能因氧化與還原條件不同，而呈現不同的黃褐色、青色、灰色、深色。
  • 含銅釉：可能因燒成氣氛不同，而產生不同的綠色、青綠色、紅色系。

因此，陶瓷釉色並不能只依照：「加入多少色料」來判斷。真正影響釉色的因素還包括：釉藥配方、金屬氧化物種類、燒成溫度、還原氣氛、還原時間、冷卻方式。

六、還原燒與電窯

一般電熱窯可以還原燒嗎？

一般傳統電熱窯，主要是利用電熱線加熱。窯內沒有直接燃燒火焰，因此通常以氧化燒為主。

電窯最大的優點是：溫度控制穩定、可設定燒成程式、升溫速度容易控制、保溫時間容易設定、重複性較高。因此，一般電窯非常適合：氧化燒、釉藥測試、色釉測試、結晶釉燒成、建立穩定的燒成資料。

電窯利用電阻加熱元件產生熱量，並透過溫度控制系統監測與調整窯內溫度，因此可以依照設定控制溫度的升降。

二、特殊電熱窯的還原燒

現代部分特殊設計的電窯，可以進行還原燒。這類窯爐通常必須具有：氣氛控制系統、特殊進氣或排氣設計、還原氣氛控制設備。

因此，不能把所有電窯都視為可以進行還原燒。可以簡單理解為：一般電熱窯主要進行氧化燒。具有特殊氣氛控制設計的電窯，才可以進行還原燒。

電窯進行還原燒的最大特色，是：溫度控制較精確。但其還原氣氛的形成與控制方式，必須依照窯爐設備本身的設計與操作規格進行。

七、還原燒與瓦斯窯

瓦斯窯是最常見的還原燒窯爐之一。瓦斯窯利用瓦斯燃燒產生高溫。與電窯最大的不同是：瓦斯窯具有火焰與燃燒氣體，因此可以直接控制窯內氣氛。

燒窯者可以透過調整：燃料供應、空氣供應、燃燒狀態、窯內壓力、排煙與通風，來改變窯內的氧氣量。因此，瓦斯窯可以進行：氧化燒、中性燒成、還原燒。

瓦斯窯可以透過調整瓦斯供應與通風系統來控制氧氣量，形成不同的燒成氣氛；其中降低氧氣量可以形成還原燒成。

八、瓦斯窯還原燒的特色

瓦斯窯還原燒最大的特色是：可以較直接地控制「火」與「空氣」之間的關係。

如果空氣供應較充足，燃燒會較接近氧化氣氛。如果燃料與空氣比例改變，使窯內氧氣供應減少，就可能形成還原氣氛。

因此，瓦斯窯的操作重點包括：火焰、溫度、空氣、瓦斯壓力、排氣、還原時間。這些因素必須同時觀察。所以：瓦斯窯還原燒，不只是控制溫度，更是控制窯內氣氛。

九、還原燒與柴燒窯

柴燒窯是最具有自然變化的燒成方式之一。柴燒窯利用木柴燃燒產生熱能。與電窯、瓦斯窯不同的是：柴燒窯中的燃料、火焰、灰燼與空氣會同時影響作品。

因此，柴燒窯的還原氣氛通常比電窯或瓦斯窯更加複雜。因為柴燒過程中，窯內可能出現：氧化氣氛、還原氣氛、強還原區、弱還原區。而且不同位置可能同時存在不同的燒成環境。

所以：柴燒窯的每一個位置，都可能有不同的效果。柴燒窯以木材提供熱能，火焰與灰燼在窯內流動，灰燼會落在作品表面並在高溫下形成自然灰釉與火痕，因此作品往往具有高度變化性與不可完全預測的特色。

十、柴燒窯的還原燒特色

柴燒與瓦斯窯最大的不同是：柴燒不只是控制氣氛，也同時受到火焰與灰燼的直接影響。

在柴燒過程中：

  • 火焰：可能直接接觸作品。
  • 灰燼：可能落在作品表面。
  • 窯內氣氛：可能隨著燃燒狀態改變。
  • 裝窯位置：會影響作品接受火焰與灰燼的程度。

因此，同一窯作品可能出現：深淺不同的顏色、火痕、落灰效果、自然灰釉、局部還原效果、不同的表面質感。這些都是柴燒的重要特色。

十一、柴燒中的氧化與還原

柴燒窯並不是整個燒成過程都保持完全相同的氣氛。在不同燒成階段中，可能出現：

  • 空氣較充足：形成較偏氧化的環境。
  • 氧氣減少：形成較偏還原的環境。

因此，柴燒的還原效果往往與：加柴節奏、燃燒狀態、窯內通風、裝窯位置、火焰流動有密切關係。所以柴燒的特色是：每一件作品都可能因所在位置不同，而產生不同的窯變。這也是柴燒作品很難完全複製的原因。

十二、電熱窯、瓦斯窯與柴燒窯的比較

比較項目 電熱窯 瓦斯窯 柴燒窯
熱源電能瓦斯燃燒木柴燃燒
一般氣氛氧化可氧化或還原氣氛變化較複雜
還原能力特殊設備才可很適合可以產生還原區
溫度控制較精確需要人工調整變化較大
重複性較高中等較低
火焰無有有
灰燼影響無通常較少明顯
作品變化較穩定變化豐富變化最大

從三種窯爐可以看出：電窯重視穩定與精確。瓦斯窯重視溫度與氣氛的控制。柴燒窯則結合火焰、灰燼、溫度與氣氛的自然變化。這些差異也使同一種陶土與釉藥，在不同窯爐中可能呈現完全不同的作品效果。

十三、還原燒的溫度控制

還原燒並不是從開始到結束都保持相同的氣氛。設計還原燒時，除了溫度曲線之外，也需要思考：

  1. 1. 何時開始還原？不同坯體與釉藥，對還原開始的時間可能有不同需求。
  2. 2. 還原持續多久？還原時間會影響部分釉藥的發色。
  3. 3. 還原強度如何？不同釉藥適合的還原程度不同。
  4. 4. 最高溫是多少？需要符合陶土與釉藥的成熟溫度。
  5. 5. 如何冷卻？冷卻速度也可能影響最終釉面與顏色。

因此，一條完整的還原燒曲線，可以概念性理解為：
升溫 → 調整氣氛 → 控制還原 → 到達最高溫 → 保溫 → 控制冷卻

十四、還原燒與冷卻

還原燒完成後，並不代表控制工作完全結束。冷卻同樣可能影響：釉色、光澤、結晶、表面質感。

因此，有些燒成會在不同冷卻階段，採取不同的氣氛控制方式。可以記住：燒成結果不是只在最高溫決定。從開始升溫到最後冷卻，每個階段都可能影響作品。

十五、還原燒常見的問題

  • 問題一：釉色與預期不同
    可能與還原程度、還原時間、最高溫度、釉藥厚度、冷卻速度有關。
  • 問題二：同一窯作品顏色不同
    可能原因包括窯內溫度不同、氣氛分布不同、裝窯位置不同、火焰流動不同。這種情況在瓦斯窯與柴燒窯中可能更加明顯。
  • 問題三：還原效果不穩定
    可能原因包括窯內氣氛變化過大、還原開始時間不同、燒成條件沒有完整紀錄。因此，每次燒窯都應該進行紀錄。

十六、建立自己的還原燒紀錄

每次還原燒完成後，可以記錄：

  • 基本資料：窯爐種類、燒成日期、陶土種類、釉藥名稱。
  • 溫度資料：升溫速度、最高溫度、保溫時間、冷卻方式。
  • 氣氛資料：還原開始時間、還原持續時間、還原程度、燒成氣氛變化。
  • 作品結果：釉色、光澤、表面質感、流動程度、窯變效果。

長期累積這些資料，就可以逐漸建立：自己的還原燒成資料庫。

十七、三種窯爐的核心特色

  • 電熱窯
    核心：溫度控制。適合追求：穩定、精確、重複性。一般電窯以氧化燒為主，特殊設計的氣氛控制電窯才可進行還原燒。
  • 瓦斯窯
    核心：火與氣氛控制。適合追求：氧化與還原變化、釉色變化、還原釉效果。瓦斯窯是學習還原燒的重要窯爐之一。
  • 柴燒窯
    核心：火、灰與自然窯變。適合追求：火痕、落灰、自然灰釉、豐富窯變、每件作品不同的自然效果。柴燒的魅力就在於：即使使用相同的陶土與釉藥，每件作品仍然可能呈現不同結果。

十八、還原燒的核心觀念

學習還原燒時，可以記住：還原燒不是單純「少給氧氣」。真正的還原燒，需要同時理解：

  1. 1. 溫度：決定坯體與釉藥是否成熟。
  2. 2. 時間：影響燒成與還原反應。
  3. 3. 氣氛：決定還原效果與部分釉色變化。
  4. 4. 窯爐：不同窯爐有不同的控制方式。
  5. 5. 冷卻：可能影響最後的釉面與顏色。
因此可以簡單記住：
還原燒效果 = 配方 + 溫度 + 時間 + 氣氛 + 窯爐 + 冷卻

十九、結論

還原燒是陶瓷燒成技術中非常重要的一種方法。它最大的特色是：透過控制窯內氣氛，改變陶土與釉藥中的部分氧化物反應，產生不同的釉色與表面效果。

不同窯爐有不同特色：

  • 電熱窯：重視溫度穩定與精確控制。一般電窯主要以氧化燒為主，特殊氣氛控制型電窯才可進行還原燒。
  • 瓦斯窯：重視火焰與窯內氣氛的控制。是進行還原燒的重要窯爐。
  • 柴燒窯：重視火焰、灰燼、氣氛與自然窯變。每件作品都可能因火焰與位置不同，形成獨特的效果。

因此，還原燒最重要的不是：把窯燒到最高溫。而是學習如何理解：火、氧氣、溫度、時間與材料之間的關係。當我們開始了解這些因素，就會發現：還原燒不只是燒成技術，更是一種控制火與氣氛的陶瓷藝術。

常見問題 (FAQ)

Q：如果我用瓦斯窯燒還原，釉藥裡的玻璃質結合會不會受到影響？

A：還原氣氛主要影響的是金屬氧化物的價態與發色，對組成玻璃質的基礎原料（如二氧化矽、長石等）的熔融行為影響較小。但某些助熔劑（例如氧化鐵被還原後）可能會表現出更強的助熔效果，這有時會讓釉面看起來更具流動感或更為溫潤，因此還是會間接影響玻璃質的最終狀態。

Q：還原燒時窯內會產生黑煙嗎？

A：是的，為了製造還原氣氛（缺氧狀態），燃燒往往不完全，因此窯煙中會帶有較多的一氧化碳與未燃燒的碳微粒（黑煙）。因此在進行還原燒時，窯房必須有極佳的通風設備，以確保操作人員的安全。
